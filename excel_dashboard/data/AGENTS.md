# data — 버전 관리 정적 데이터

## 범위
- `contest_universe_20260930.csv`: 대회 종목 고정 명단(527행). 빌더가 정적 표 `tblContest`로 넣는다.
- `themes_base.csv`: 대회 종목의 기본 테마표(대테마 20·세부테마 76). 빌더가 정적 표 `tblThemeBase`로 넣는다.
- `nics_codes.csv`: NICS 대분류 11·업종 26 고정 코드표(37행). 쿼리 `fnNicsCodes` 안에 같은 표가 들어 있다.
- 하지 않는 것: 사용자 수정(통합문서 [설정]의 수정표가 함), 실시간 데이터.

## 불변식
- 세 파일 모두 UTF-8 BOM, 쉼표 구분, 종목코드는 6자리 텍스트(선행 0, 영문 포함 코드 10개 — `0126Z0` 등). 숫자로 바꿔 저장하면 선행 0과 영문 코드가 깨진다.
- 명단 열: 종목코드, 종목명, 시장(KOSPI/KOSDAQ), 시가총액_0930_억, 평균거래대금_5일_억(소수 둘째 자리, 판정은 원 단위 원값), 거래일수(1~5), 상장주식수(9/30), 비고(`""`/`외국기업`/`5일 미만`/`외국기업; 5일 미만`). 시가총액 내림차순, 같으면 코드순. 손으로 고치지 않고 생성 스크립트를 다시 돌린다(기준일·세션·하한이 인자).
- 테마표 열: 종목코드, 종목명, 대테마, 세부테마, 근거(주요 제품·사업 한 줄). 종목 집합과 순서는 명단과 같고, 종목당 대테마·세부테마 각 1개, 세부테마는 항상 한 대테마에만 속하며 1종목뿐인 세부테마를 만들지 않는다. 바꾼 뒤 `python excel_dashboard/tools/theme_helper.py check`가 종료 코드 0이어야 한다.
- 코드표 열: 코드(`N10000` 형식), 이름, 단계(대분류/업종). 바꾸면 `fnNicsCodes`의 표도 같이 바꾼다.
- 파일을 바꾼 내용은 다시 빌드해야 통합문서에 반영된다(통합문서 안 정적 표는 빌드 때 채워짐).

## 시험
- 명단: 종목 수·시장별 수, 005930·000660 포함, 우선주(005935 등)·SPAC 제외, 모든 행이 두 기준 이상, 경계 ±10% 종목을 다른 API로 재판정.
- 테마표: `theme_helper.py check`(코드 집합·순서·계층·빈 칸·BOM·머리글·이름 일치).
- 코드표: `fnNicsCodes` 결과와 행 단위 비교.
