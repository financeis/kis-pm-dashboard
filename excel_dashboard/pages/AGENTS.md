# pages — 새 페이지 빌더

## 범위
- `page_company.py`(대회종목), `page_sector.py`(업종), `page_analysis.py`(종목분석), `page_news_events.py`(뉴스·이벤트). 각 모듈이 시트 하나를 통째로 소유해 제목 띠·버튼·최근 조회/상태 칸·이름 정의·표 서식·조건부 서식·열 묶음·차트를 그린다.
- 하지 않는 것: 데이터 계산(쿼리가 함), 표 적재·시트 순서·내비 항목·VBA 삽입·저장(빌더가 함), 기존 시트(대시보드·시장 등 — 빌더의 `build_*` 메서드).

## 모듈 계약
- 내보내는 것: `SHEET`(시트 이름), `LOADS = [(쿼리, 표, 머리글 왼쪽 위 셀), …]`, `prepare_tables(builder)`(뉴스·이벤트는 없음), `build(builder)`.
- 빌더 순서: `LOADS` 위치에 표 적재 → `prepare_tables` → 첫 새로 고침 → `build`. `prepare_tables`는 각 표에 `QueryTable.RefreshStyle = 0`(대회종목은 `PreserveFormatting = True`, `AdjustColumnWidth = False`도)을 건다. `build`는 같은 값을 다시 걸어도 되지만 되돌리지 않는다.
- `build(builder)`가 쓰는 것: `builder.wb`·`ws[시트]`·`lo[표]`·`table_style`·`say()`·`nav_links(ws, 4)`·`HEADER_RIGHT`·`HEADER_STATUS`와 `xl_helpers` 함수. 표가 없거나 열이 다르면 `say()`로 경고하고 그 블록만 건너뛴다. 두 번 불러도 결과가 같아야 한다(시트의 조건부 서식·하이퍼링크를 지우고 다시 그림).
- 이름 정의(통합문서 범위, VBA가 첫 셀에 씀): 대회종목 `시세_최근조회` D6·`시세_상태` G6·`전체_최근조회` D7·`전체_상태` G7 / 업종 `업종_최근조회` D7·`업종_상태` E7 / 종목분석 `분석코드` D6(텍스트 서식)·`분석_최근조회` M6·`분석_상태` P6·`대회코드목록` = `tblContest[종목코드]`. 버튼은 `xl_helpers.add_button`으로 `RefreshQuick`·`RefreshFull`·`RefreshSector`·`RunAnalysis`에 연결.

## 불변식
- 표에 행을 추가·삭제하지 않는다(`ListRows.Add`/`Delete`, 임시 행 금지 — 쌓인 표는 Excel이 거부하고 삭제는 아래 블록을 끌어올림). 예외는 뉴스·이벤트 페이지 하나: 두 표가 나란히 있고 아래에 다른 표가 없어서, 빈 표에 서식을 걸 때만 임시 행 1개를 넣었다가 지운다. 서식·조건부 서식은 표 아래 최대 행 수만큼 예약한 고정 범위에 건다(대회종목 1,200행, 업종 A 56행·B 150행, 뉴스·이벤트 1,500·600행, 종목분석은 표마다 최대 행).
- 표 사이 간격은 그 표의 최대 행 수보다 커야 한다(종목분석 투자자 120행, 당일 매물대 100행, 프로필 20행 …). 적재 셀을 바꾸면 `LOADS`만 고친다(빌더는 `LOADS`를 그대로 씀).
- Q.Pack 3색은 변화·비율 열에만, 기준점은 숨김 칸의 수식(`write_qpack_anchors` 또는 같은 방식)으로 조건 행만(대회종목 `유니버스="대회"`, 업종 A `구분="업종"`, 업종 B `단계="세부테마"`). 1행·빈 표에서 기준점이 0이 되지 않게 `tbl[[#All],[열]]` 범위나 SUMPRODUCT 가드를 쓴다. 줄무늬는 20열 한 블록의 5·50·95 백분위, 값 숨김(`;;;`)·폭 약 2.5.
- 열 묶음은 같은 수준의 묶음이 나란히 붙으면 합쳐지므로 각 묶음 왼쪽에 보이는 비그룹 열을 둔다(대회종목: 최근분기·PER변화3M·신용잔고율·다음이벤트·NICS 대분류·유의를 보이게 둠). 기본 상태는 접힘.
- 차트는 표 열에 직접 묶지 않는다(0행 표에 만들 수 없고 1행에서 만든 계열은 늘지 않음). 행 수를 세는 숨은 시트 범위 이름(종목분석 `분석차트_*`, 보조 열 BD:BF)이나 고정 행 수 표의 고정 범위를 쓴다.
- D-day는 저장값(자정 뒤 낡음) 대신 일자에서 다시 계산해 보여 준다(조건부 숫자 서식 등).
- 숫자 서식은 현지화 코드(`set_nf`), 조건부 서식은 대상 첫 셀 선택 후 위치 인수. 보유 행 강조는 시세판과 같은 옅은 색이고 Q.Pack 규칙이 그보다 우선한다(`SetFirstPriority`).

## 시험
- `tools/pq_harness.py`의 `Harness(use_token=False)`로 표를 정적 표(샘플 CSV/JSON)로 `LOADS` 위치에 만들고 대역 빌더 `h.builder()`로 `build()` → `h.render(시트, png)`로 확인.
- 실제 PQ 표로 0행 → N행 → 0행 → N행 새로 고침(인라인 쿼리나 시드를 쓴 build 모드 쿼리): 조건부 서식 규칙 수·적용 범위·차트 범위·표 위치 불변, 새로 고침 중 Excel이 죽지 않음.
- 색: `Range.DisplayFormat.Interior.Color`로 최소 → `#63BE7B`, 최대 → `#F8696B`, 빈칸 → 배경색만. 대회 밖 행에 극단값을 넣어도 기준점 불변.
- 이름 정의 범위(통합문서)와 버튼 `OnAction`, `.xlsm` 저장·다시 열기 뒤 유지.
