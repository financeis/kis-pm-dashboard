# 외부 계약

이 프로젝트의 소비자는 통합문서를 쓰는 사용자, 통합문서를 자동으로 돌리는 스크립트(검증 도구·VBA 호출), 데이터 파일을 읽고 쓰는 도구다. 아래 약속이 깨지면 그 소비자가 깨진다.

## 공통 규약

- 종목코드는 6자리 텍스트(선행 0 유지, 영문 포함 가능). 금액 억원, 비율은 소수(화면 표시는 %), 배수는 배. 데이터 없음은 빈칸(0 아님).
- Power Query가 채우는 표의 `상태` 값: `OK` / `데이터 없음` / `추정 없음`(정상), `오류: <사유>`(그 행·종목만 실패), `이전 데이터(갱신 실패: <사유>)`(표 전체가 직전 데이터). `조회시각`은 그 행을 마지막으로 받은 시각.
- 버튼 결과(최근 조회 시각 옆 상태 칸): `정상` / `일부 오류 n건` / `실패: <단계들> — 이전 데이터 표시 중`, 실행 전에는 `아직 실행 안 함`·`조회 전`·`-` 같은 초기 문구.

## 버튼과 이름 정의 (통합문서)

| 버튼 | 매크로 | 기록하는 이름(통합문서 범위) | 실행 순서 |
|---|---|---|---|
| [시세] (대회종목) | `RefreshQuick` | `시세_최근조회`(D6) · `시세_상태`(G6) | T_Token → T_Sessions → T_PxStore → T_PxMetrics → T_Company → T_ThemeAgg |
| [전체] (대회종목) | `RefreshFull` | `전체_최근조회`(D7) · `전체_상태`(G7) | T_Token → T_Class → T_Sessions → T_PxStore → T_PxMetrics → T_FlowU → T_Target → T_Est → T_EstSnap → T_Events → T_Fin → T_CSL → T_Company → T_ThemeAgg → T_SectorKRX → 이력 CSV |
| [업종] (업종) | `RefreshSector` | `업종_최근조회`(D7) · `업종_상태`(E7) | T_Token → T_SectorKRX → T_ThemeAgg |
| [조회] (종목분석) | `RunAnalysis` | `분석_최근조회`(M6) · `분석_상태`(P6), 입력 `분석코드`(D6, 텍스트) | T_Token → `tblA_*` 전부(`…Seed` 제외) |

- 최근 조회 칸에는 실행이 끝난 시각(날짜·시간 값)이 들어간다. `대회코드목록` = `tblContest[종목코드]`(종목분석 드롭다운 원천, 목록 밖 코드도 입력 가능).
- 자동화용 VBA 함수: `JudgeTable(표이름)` → `"판정|건수|사유"`, `SaveEstSnapCsv()` → 같은 형식, `FixLocalPaths()` → 바꾼 설정 경로(`키 -> 경로` 줄들, 없으면 빈 문자열), `RefreshedTables()` → 이번 Excel 세션에서 새로 고침에 성공한 표 목록(준비든 본 단계든, 소문자·쉼표로 이음 — [전체]는 여기 없는 표만 준비한다).

## 실행 제어 표 `tblRunCtl` (숨김 `_seed`, 열 `키`·`값`)

| 키 | 누가 쓰나 | 의미 |
|---|---|---|
| `mode` | 매크로 | `quick`·`full`·`sector`·`analysis` 실행 중, 끝나면 항상 `build`. 빈칸·알 수 없는 값 = `build`(버튼 쿼리 KIS 호출 없음) |
| `started` | 매크로 | 이번 버튼 실행 시작 시각(날짜 값). 쓰기에 실패하면 실행 중단. 자동화가 미리 넣지 않는다 |
| `now_override` | 시험만 | 일시 — 세션 달력·가격 저장소가 '지금'으로 씀(모사 날짜 뒤 날짜를 달력에서 빼고, 09:00 전이면 오늘도 뺌). 평소 빈칸, 시험 뒤 비움 |
| `quiet` | 사용자·자동화 | `Y`면 요약 창을 띄우지 않음(숨김 Excel에서는 원래 안 띄움) |
| `last_summary` | 매크로 | 단계별 판정·사유·소요 시간 요약(여러 줄) |

## 사용자 입력표

- **매매일지** `tblTrades`: 일자, 종목코드, 종목명(수식), 구분(매수/매도), 수량, 단가, 금액(수식), 수수료, 세금, 전략, 매매근거, 목표가, 손절가 … 확인 열: `✓` / `⚠ 종목DB에 없는 코드` / `⚠ 구분 확인` / `⚠ 대회 종목 아님`.
- **관심종목** `tblWatch`(종목코드·종목명(수식)·그룹·투자포인트 …), **해외지수 목록** `tblMacro`, **휴장일** `tblHolidays`.
- **수정표** `tblOverride`([설정] W8): 종목코드, 대회편입(공란/`추가`/`제외`), 대테마, 세부테마, NICS 대분류, NICS 업종, NICS 세부, 메모. 공란 = 수정 없음, 항상 기본 분류보다 우선. 잘못된 행(코드 형식·`대회편입` 값이 틀리거나 종목DB에 없는 코드)은 분류에 반영되지 않고 AB5에 그 행 수가 `⚠ 수정표 n행 무시됨(종목코드·값 확인)`으로 뜬다.
- **설정** `tblSettings`(키·항목·값·설명): 키는 고정 문자열, 재생성 때 키별로 사용자 값 유지. 예외: `cfg_path`·`vs_path`가 그 PC에 없는 파일을 가리키고 표준 위치에 파일이 있으면 빌더(기본 위치)와 매크로 `FixLocalPaths`(사용자가 열 때 `Auto_Open`, 모든 버튼 시작)가 그 PC 경로로 바꾼다.

## 주요 출력표 (다른 화면·스크립트가 읽음)

- `tblCompany`(대회종목!B13, 103열, 순서 고정): 기본(종목코드·종목명·시장·구분·유니버스·NICS 업종·대테마) → 규모(시가총액억·거래대금60일억·거래량60일천주) → 가격(현재가·고52주대비·가격기준일) → 1D·1W·1M·3M·6M·YTD·1Y → D-19…D0 → 외국인1D%·1W%·1M%·1D억·1W억·1M억 → 기관 같은 6열·수급기준일 → 후행PER·PBR → FwdPER·FwdPER변화1W·1M·FwdEPS·추정일·FY1·FY1_EPS·FY2·FY2_EPS → 목표가평균·괴리율·증권사수·목표가변화1M·3M·최근의견일·최근증권사·최근의견 → 최근분기·매출YoY·영업이익YoY·순이익YoY·실적상태·ROE → PER변화3M·6M·YTD·1Y·PBR변화 4개 → 신용잔고율·신용잔고율1M변화·공매도비중5일·대차잔고1M변화율·신용기준일 → 다음이벤트·다음이벤트일 → NICS 대분류·NICS 세부·세부테마·KSIC 세분류·주요상품·기업집단·분류출처 → 유의·상태·조회시각.
- `tblThemeAgg`(업종!B80): 단계(대테마/세부테마), 대테마, 세부테마, 종목수, 시가총액억, 1D…1Y, 상승비율1D·1W, 외국인1D%·1W%·1M%, 기관1D%·1W%·1M%, 상태, 조회시각.
- `tblSectorKRX`(업종!B15): 시장, 코드(4자리 텍스트), 업종명, 구분(업종/대분류), 기준일, 지수, 1D…1Y, 외국인·기관·개인 1D·1W·1M억, 상태, 조회시각.
- `tblUniverse`(종목DB): 기존 열 + 대회편입(Y/N, 새 규칙)·섹터(설정 기준)·대분류(NICS)·NICS 업종·NICS 세부·대테마·세부테마·분류출처·대회비고·KRX업종.
- `tblRank`: 기존 열 + 대회(`★`/공란). `tblQuote`: 기존 열 + 대테마·다음이벤트·신용잔고율·공매도비중5일·추정시점·추정외국인주·추정기관주·추정합산억.
- `tblEstSnap`(영구): 일자, 종목코드, FwdEPS, 종가, FwdPER, 추정일, 상태, 조회시각.

## 파일

- `data/contest_universe_20260930.csv` — UTF-8 BOM, 527행, 열: 종목코드, 종목명, 시장(KOSPI/KOSDAQ), 시가총액_0930_억, 평균거래대금_5일_억(소수 둘째 자리, 판정은 원 단위 원값), 거래일수(1~5), 상장주식수(9/30), 비고(`""`/`외국기업`/`5일 미만`/`외국기업; 5일 미만`). 시가총액 내림차순.
- `data/themes_base.csv` — UTF-8 BOM, 열: 종목코드, 종목명, 대테마, 세부테마, 근거. 명단과 같은 종목·같은 순서.
- `data/nics_codes.csv` — UTF-8 BOM, 열: 코드, 이름, 단계(대분류/업종), 37행.
- `history/est_snap.csv` — 통합문서 옆, UTF-8 BOM·CRLF, 머리글 = `tblEstSnap` 열, 날짜 `yyyy-mm-dd`(일시 `yyyy-mm-dd hh:nn:ss`), 소수점 `.`, 쉼표·따옴표 포함 텍스트는 따옴표. 재생성 때 통합문서에 스냅샷이 없으면 이 파일로 복원. 새 스냅샷 표가 기존 파일보다 행이 적거나 기존 파일을 읽을 수 없으면 기존 파일은 그대로 두고 `history/est_snap_yyyymmdd_hhnnss.csv`가 따로 생긴다.
- VALUESearch 내보내기 — 시트 `Sheet2`, 1행 머리글, `종목코드`는 `A######`, NICS 열은 `N#####.이름`. 열 이름이 다르면 분류는 직전 값을 유지하고 상태에 사유.

## 빌드 명령 (스크립트용)

- `build_dashboard.py` 인자: `--out`, `--migrate-from`, `--no-migrate`, `--cfg`, `--empty`(이관 원본이 없을 때만), `--visible`, 숨은 인자 `--vbom-lock <잠금 파일>`(여러 작업이 AccessVBOM을 동시에 만질 때 상호 배제), `--seed-token`, `--checkpoint`, `--resume`(체크포인트에서 이관 없이 다시 만듦 — 기본 출력이 아닌 `--out`을 함께 줘야 하고, 아니면 Excel을 띄우기 전에 종료 코드 3).
- 종료 코드 0 성공 / 1 빌드 실패 / 2 토큰 갱신 필요 / 3 이관·설정 문제(2·3은 Excel을 띄우기 전에 멈춤).
