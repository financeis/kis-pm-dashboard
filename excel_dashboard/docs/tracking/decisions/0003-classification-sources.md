# 0003. 분류 = VALUESearch NICS + Claude 테마 기본표 + 사용자 수정표

## 배경
Q.Pack처럼 자세한 업종 분류가 필요했지만 KIS에는 WICS 같은 세분 분류가 없고 KRX 지수업종은 너무 거칠다. 사용자는 VALUESearch에서 NICS 분류를 내보낸 파일을 가지고 있었다. NICS도 '자본재'가 대회 종목의 약 20%이고 '기계'에 조선·방산·원전이 섞여 투자 관점의 묶음이 따로 필요했다.

## 결정
업종은 VALUESearch 파일의 NICS 3단계(파일에 없으면 KRX 지수업종), 투자 테마는 Claude가 만든 대테마·세부테마 기본표(`data/themes_base.csv`), 그 위에 사용자 수정표가 항상 우선한다. 기존 화면의 '섹터'는 설정(`sector_basis`)으로 대분류·업종·세부·대테마 중 고르고 기본은 세부다.

## 대안
- WICS 공개 페이지 조회: 외부·비공식이라 채택하지 않음.
- KRX 지수업종만: 너무 거침.
- 기본표를 사용자가 직접 고치기: 기본표를 새 버전으로 바꾸면 수정이 사라진다 → 기본표/수정표 분리.

## 결과
- 분류는 사용자가 VALUESearch 파일을 갱신해야 새 상장 종목이 들어간다(없으면 KRX로 대체).
- 대회편입·NICS·테마·섹터 판정은 `fnClassify`/`fnPageRows` 한 곳에서만 하고 모든 화면이 쓴다. 다른 곳에서 다시 구현하면 화면마다 판정이 달라진다.
- 수정표·섹터 기준을 바꾸면 종목DB를 읽는 화면은 [모두 새로 고침]을 두 번 해야 반영된다.
