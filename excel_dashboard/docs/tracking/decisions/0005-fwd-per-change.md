# 0005. Fwd PER 변화는 스냅샷 + 추정일 기반 재구성

## 배경
Q.Pack의 Fwd PER change를 원했지만 KIS 추정실적 API는 지금 추정만 주고 과거 추정 이력이 없다. 외부 컨센서스는 쓰지 않기로 했다.

## 결정
[전체]마다 (가격기준일, 종목)별 Fwd EPS·종가·Fwd PER·추정일을 영구 스냅샷으로 쌓는다. 1W·1M 변화의 기준값은 기준 세션 이전 3세션 안의 가장 가까운 스냅샷, 없고 현재 추정의 추정일이 기준일보다 앞서면 추정치가 그동안 같았으므로 기준일 종가 ÷ 기준일 가중치의 Fwd EPS로 재구성한다. 스냅샷은 매 [전체] 뒤 `history/est_snap.csv`에도 복사한다.

## 대안
- 변화를 비워 두기: 첫날부터 쓸모가 없다.
- 외부 컨센서스 이력: 사용자가 채택하지 않음.

## 결과
- 추정치가 바뀐 구간은 스냅샷이 쌓여야 채워진다. 버튼을 안 누른 날은 3세션 안의 스냅샷이나 재구성으로 메우고, 둘 다 없으면 공란.
- 스냅샷 표는 지우지 않는 영구 이력이라 재생성 때 반드시 이관해야 하고, 통합문서에 없으면 이력 CSV에서 복원한다.
- KIS 추정은 이 종목군의 약 21%만 있어 Fwd PER 열 대부분이 빈칸이다(정상).
