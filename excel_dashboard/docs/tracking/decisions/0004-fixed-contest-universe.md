# 0004. 대회 종목은 9/30 기준 고정 명단 파일

## 배경
대회 규정: 시가총액 1,000억 이상·5거래일 평균 거래대금 25억 이상 보통주, 9/30 기준으로 한 번 정하고 고정. 매일 규칙을 다시 계산하면 대회 중 종목군이 흔들리고, 무엇을 기준으로 했는지 재현하기 어렵다.

## 결정
생성 스크립트(`tools/make_contest_universe.py`, 기준일·세션·기준값을 인자로)가 KIS 마스터와 일봉으로 한 번 판정해 `data/contest_universe_20260930.csv`로 버전 관리하고, 빌더가 정적 표 `tblContest`로 넣는다. 결과는 527종목(KOSPI 236·KOSDAQ 291).

## 대안
- 통합문서 안에서 매일 규칙 계산: 고정 규정과 맞지 않고 호출 수천 회.
- 하루 거래대금 기준 어림(약 488): 규정은 5세션 평균이다.

## 결과
- 거래정지·상장폐지가 생겨도 명단에 남고 상태만 표시된다. 예외는 수정표 `추가`·`제외`로 처리한다.
- 대회 뒤 종목군 정책은 정해지지 않았다. 바꾸려면 스크립트를 새 기준으로 돌려 파일을 바꾸고 다시 빌드한다.
