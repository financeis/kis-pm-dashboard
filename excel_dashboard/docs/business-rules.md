# 업무 규칙

## 용어

- **세션**: KRX 영업일. 기간 계산은 달력일이 아니라 세션 수로 한다. **세션 달력**은 KOSPI 지수(0001) 일봉에 나타난 날짜들이며 수작업 휴장일 목록에 의존하지 않는다(휴장일 목록은 오늘 개장 여부 API가 실패했을 때의 대체 판단에만 쓴다).
- **마지막 세션**: 세션 달력의 가장 최근 날짜 — 장 시작 전·휴장일에는 직전 영업일, 장중·장 마감 후에는 오늘.
- **완료 세션**: 장 마감 15:30이 지난 세션. 장중의 오늘은 진행 중 세션이다.
- **대회 종목**: 고정 명단 ± 수정표의 추가·제외. **페이지 행** = 대회 종목 ∪ 보유·관심 종목 중 대회 종목이 아닌 것.
- **구분**(보유·관심 여부): `보유` / `관심` / `보유·관심` / 공란. **유니버스**: `대회` / `유니버스 밖`.
- **보유**는 매매일지로 계산한 보유수량 > 0인 종목, **관심**은 [설정] 관심종목 표의 종목이다.

## 대회 종목 명단

- 규칙(두 조건 모두, 경계 포함 '이상'): 2026-09-30 종가 × 상장주식수 ≥ 1,000억원, KRX 거래대금(시장구분 J — NXT 제외)의 2026-09-22·23·28·29·30 평균 ≥ 25억원. 대상은 개별종목(종류 ST·FS·DR) 중 우선주·SPAC 제외, 리츠·ETF·ETN·펀드는 원래 제외. FS·DR은 포함하고 비고 `외국기업`.
- 상장 전이라 빠진 세션은 평균에서 빼고 비고 `5일 미만`, 상장 중인데 거래가 없던 세션은 0으로 평균에 넣는다. 상장주식수는 9/30 기준(이후 추가상장분은 뺌).
- 결과 527종목(KOSPI 236·KOSDAQ 291)이며 자동으로 바뀌지 않는다. 이후 거래정지·상장폐지돼도 명단에 남고 상태·유의 열에만 표시한다.
- 명단을 다시 만들 때는 기준일·세션·기준값을 인자로 바꿔 생성 스크립트를 돌린다(대회 뒤 정책은 정해지지 않았다).

## 분류

- **NICS**(VALUESearch 파일의 `N#####.이름`): 대분류 코드 = 앞 3자리 + `000`, 업종 = 앞 4자리 + `00`, 세부 = 원래 코드. 대분류·업종 이름은 고정 코드표(11개 대분류, 26개 업종), 세부 이름은 파일의 이름. 업종 수준까지만 분류된 종목은 세부 = 업종 이름, 대분류까지만이면 업종 = 세부 = `대분류이름 (기타)`. 코드표에 없는 코드(예: `N00000`)는 단계를 비우고 KRX로 대체한다.
- 파일에 없거나 NICS가 빈 종목은 KRX 지수업종 이름을 세 단계 모두에 넣고 `분류출처 = KRX`, 파일에서 온 것은 `NICS`. KRX 업종도 없으면 비운다.
- **테마**: 대회 종목마다 대테마 1개 + 세부테마 1개(대테마 20·세부테마 76). 세부테마는 항상 한 대테마 아래에만 있다. 대회 종목이 아닌 페이지 행은 수정표로 지정하지 않으면 테마 공란.
- **우선순위**: 기본(명단·NICS 파일·기본 테마표) 위에 수정표의 비어 있지 않은 칸이 **항상** 우선한다. 기본표가 새 버전으로 바뀌어도 수정표가 이긴다. 수정표가 분류를 바꿔도 `분류출처`는 NICS/KRX 그대로다.
- **수정표 행 검증**: 종목코드를 대문자로 바꾸고 숫자만 있는 6자리 미만 코드는 앞을 0으로 채운 뒤, 6자리 [0-9A-Z]가 아니거나 `대회편입`이 공란·`추가`·`제외`가 아니면 그 행 전체를 무시한다. 같은 종목의 행이 여럿이면 칸별로 합치되 아래 행의 비어 있지 않은 값이 이긴다. `추가`·`제외`는 `대회비고`에 `수정표 추가`/`수정표 제외`를 덧붙인다.
- **섹터 기준**(`sector_basis` = 대분류/업종/세부/대테마, 기본 세부, 빈칸·알 수 없는 값도 세부): 종목DB의 `섹터`가 이 값을 담고 포트폴리오·리스크·대시보드·시세판·순위가 따른다. 값이 없으면 세부 → 업종 → 대분류 → KRX 순으로 대체한다.

## 가격 이력과 지표

- 저장소는 페이지 행 종목마다 일봉(수정주가) 최소 260세션, (종목코드, 일자)마다 1행, 세션 달력 밖 날짜 없음.
- [시세]는 이력이 있는 종목만 **마지막 세션 봉**을 멀티 시세 값으로 추가(없으면)·갱신(있으면)한다. 장중이면 진행 중 값, 마감 후면 확정값. 장 시작 전·휴장일에는 새 봉을 만들지 않고 마지막 세션 봉만 갱신하며, 달력에 없는 날짜의 봉은 만들지 않는다. 이력이 없는 종목의 260세션 채우기는 [전체]에서만 한다.
- **안전 규칙**: 오늘이 개장일(국내휴장일조회, 하루 1회)이고 09:00 이후인데 달력에 오늘이 아직 없으면 저장소를 그대로 두고 세션 달력 표의 가장 최근 행 하나에 `오류: 오늘 세션 미확인`을 남긴다(판정 '일부 오류 1건'). 휴장일에는 작동하지 않는다.
- [전체]는 추가로 달력 대비 빠진 세션을 일봉으로 메우고, 저장소 직전 세션 종가 ≠ 멀티 시세 기준가(분할 반영 전일 종가)인 종목은 이력을 다시 받으며, 달력 밖 날짜 행을 지운다. 수정주가 변동은 시세를 받은 그 세션에서만 감지되므로 권리락일에 [전체]를 건너뛰면 그 앞 이력이 수정 전 값으로 남는다.
- 현재가 = 그 종목 마지막 봉 종가, 가격기준일 = 그 봉의 날짜(정지 종목은 마지막 세션보다 이를 수 있음). 기간 등락 = 현재가 ÷ 기준 세션 종가 − 1, 기준은 1D 직전 세션, 1W 5, 1M 21, 3M 63, 6M 126, 1Y 250세션 전, YTD 직전 연도 마지막 세션. 이력이 모자라면 공란.
- 최근 20일 줄무늬 = 마지막 세션(장중이면 오늘)을 D0로 하는 20세션의 일간 등락. 60일 평균 거래대금(억원)·거래량(천 주)은 완료 세션 60개. 52주 고가 대비 = 현재가 ÷ 최근 250세션 최고가 − 1. 시가총액 = 현재가 × 상장주식수(종목DB 값, 없으면 명단 값).

## 수급

- 종목 수급 1D·1W·1M = 외국인·기관계 순매수의 최근 1·5·21 **완료** 세션 합(억원, 백만원 ÷ 100). 오늘 행은 15:30 이후이면서 외국인·기관계·개인이 모두 0이 아닐 때만 쓴다(오늘 날짜는 15:40 전에는 API가 거부). 상장일의 0 수급 행은 뺀다. 세션이 모자라면 그 기간은 공란.
- 시가총액 대비 % = 순매수 합 ÷ 현재 시가총액(소수로 저장). 기준일을 함께 보여 준다.
- KRX 업종 수급은 같은 완료 세션 규칙이고, 업종 지수·기간 등락은 오늘 장중 값까지 쓴다(장중에는 기준일이 오늘이어도 수급은 직전 세션까지).

## 실적과 후행 밸류

- 분기 값은 회계연도 누적이라 같은 회계연도 직전 분기 누적을 빼서 단독값으로 만든다(1분기 = 누적). 직전 분기가 없으면 공란 — 추정하지 않는다. 회계연도 끝은 누적 매출이 다시 작아지는 분기로 찾는다(12월이 아닌 결산도 처리).
- 공개기준일 = 분기말 + 45일, 4분기(결산)는 결산일 + 90일(`fin_lag_q`·`fin_lag_y`로 조정). 어떤 날 d에 '알려진' 실적 = 공개기준일 ≤ d인 분기들.
- YoY = 분기 단독 ÷ 전년 동분기 − 1, 전년 값 ≤ 0이면 공란. 실적 상태(영업이익 분기 단독): 전년 ≤ 0·올해 > 0 `흑자전환`, 전년 > 0·올해 ≤ 0 `적자전환`, 둘 다 ≤ 0 `적자지속`, 둘 다 > 0 `흑자지속`.
- TTM EPS(날 d) = 공개기준일 ≤ d인 가장 최근 연속 4개 분기 단독 EPS 합, 하나라도 없으면 공란. 후행 PER = 현재가 ÷ TTM EPS, PBR = 현재가 ÷ 최근 분기 BPS. ROE는 최근 분기 행의 API 값.
- PER 변화·PBR 변화(3M·6M·YTD·1Y만) = (현재가 ÷ 오늘 알려진 EPS) ÷ (기준 세션 종가 ÷ 기준일에 알려진 EPS) − 1. 어느 쪽이든 EPS·BPS ≤ 0이면 PER·PBR과 변화는 공란(실적 상태 열이 이유를 설명).
- API가 모든 값을 0이나 99.99로 주는 종목은 `데이터 없음`이다(실제 0억도 공란으로 보임).

## 목표주가 컨센서스

- 날 D의 컨센서스 = 증권사별로 (D − 6개월, D] 안의 마지막 목표가(0·공란·음수 제외)를 모아 평균, 증권사 수 = 그 증권사 수. D−1개월·D−3개월도 같은 길이의 창으로 계산한다(`target_window_months`).
- 괴리율 = 평균 목표가 ÷ 현재가 − 1, 목표가 변화 1M·3M = 컨센서스(D) ÷ 컨센서스(D−1M·D−3M) − 1. 최근 의견은 조회 기간(약 9개월) 전체에서 가장 최근 행.
- 목표가가 없으면 공란에 상태 `데이터 없음`(정상). 이 종목군의 약 58%만 값이 있다.

## KIS 추정과 Fwd PER

- 한국투자증권 리서치 자체 추정이며 컨센서스가 아니다(이 종목군 약 21%). 연도는 응답의 연도 라벨로 맞추고, EPS와 모든 비율·배수는 값 ÷ 10, 금액은 억원 그대로.
- FY1 = 아직 끝나지 않은 가장 이른 결산(결산 연월 ≥ 이번 달), FY2 = 그다음. Fwd EPS = FY1 EPS × r/12 + FY2 EPS × (12 − r)/12, r = 이번 달부터 FY1 결산월까지 개월 수(포함; 12월 결산 10월 → 3). FY2가 없으면 FY1 EPS만 쓰고 FY2 칸에 `FY1만`. FY1 EPS가 없으면(은행 등) `추정 없음`.
- Fwd PER = 현재가 ÷ Fwd EPS, Fwd EPS ≤ 0이면 공란.
- 스냅샷: [전체]마다 (가격기준일, 종목코드)별로 Fwd EPS·종가·Fwd PER·추정일을 쌓고, 같은 날은 마지막 실행 값으로 덮는다. 행은 지우지 않으며 페이지 행에서 빠진 종목도 남긴다. 추정 상태가 `OK`인 종목만 쌓는다.
- Fwd PER 변화 1W·1M = 현재 Fwd PER ÷ 기준 세션(5·21세션 전) Fwd PER − 1. 기준 세션 이전 3세션 안(당일 포함)의 가장 가까운 스냅샷이 있으면 그 Fwd PER, 없고 현재 추정의 추정일이 기준일보다 앞서면 기준일 종가 ÷ 기준일 가중치로 섞은 Fwd EPS로 재구성, 둘 다 아니면 공란.

## 신용·공매도·대차 (주 1회)

- 신용잔고율 = 최신값, 1M 변화 = 최신 − 21세션 전(%p, 22행 미만이면 공란). 공매도 비중 = 최근 5개 완료 세션의 공매도 거래대금 ÷ 거래대금 평균(5개 미만이면 공란). 대차잔고 1M 변화율 = 최신 잔고 주수 ÷ 21세션 전 − 1. 신용은 T+2로 늦게 공표돼 기준일은 세 계열 최신일 중 가장 이른 날이다. 모든 지표가 비면 상태 `데이터 없음`.

## 이벤트·뉴스·증시 자금

- 이벤트 기간 = 오늘 − 7일 ~ 오늘 + 60일(`event_days_back`·`event_days_ahead`), 대상 = 페이지 행. 종류와 일자: `CB·BW 전환 상장`·`신규상장`(상장일), `유상증자`(신주 상장일, 없으면 청약 시작일), `무상증자`(신주 상장일, 없으면 배정 기준일), `합병·분할`(기준일), `배당 기준일`, `주주총회`(총회일). 같은 (종목, 일자, 종류, 상세)는 1건. 보유 = 구분이 보유·보유·관심이면 `Y`.
- D-day = 일자 − 오늘. 저장값은 [전체] 때 계산돼 자정이 지나면 낡으므로 화면과 '다음 이벤트'는 일자에서 다시 계산해야 한다. 다음 이벤트 = 오늘 이후 가장 가까운 이벤트(`D-n 종류`, 같은 날 여러 종류는 `·`로 연결).
- 뉴스 = 보유 ∪ 관심 종목별 최근 40건을 시간순으로 합친 최근 100건. 0건인 종목은 `오류: 뉴스 0건(종목코드 확인)` 행 1개를 따로 남긴다(실패를 보이게).
- 증시 자금(억원, 약 100영업일) — 마지막 행 일자가 기준일(1~2일 늦게 공표). 주식형은 평가액이라 주가를 따라 움직인다.

## 대회종목 표와 테마 집계

- 행 순서: 대회 종목 시가총액 내림차순(빈 값은 끝), 그 아래 유니버스 밖 종목 시가총액 내림차순. 데이터가 없으면 0이 아니라 빈칸.
- 표의 상태는 가격 지표의 상태를 따른다(첫 [전체] 전 `데이터 없음`, 가격 지표가 직전 데이터로 돌아가면 이 표도 `이전 데이터…`). 다른 원천의 빈 값은 상태를 오류로 만들지 않는다.
- 테마 집계 = `유니버스 = 대회`이고 테마가 있는 종목만. 기간 등락 = 현재 시가총액 가중 평균(그 기간 값이 있는 종목만, 가중치 재정규화), 상승 비율 = 값이 있는 종목 중 등락 > 0 비율, 수급 % = 수급 합 ÷ 수급 값이 있는 종목의 시가총액 합. 대테마 행 뒤에 그 세부테마 행들(각각 시가총액 내림차순).

## 색 비교 기준 (Q.Pack 3색)

- 변화·비율 열만 칠한다(Price change 7, 52주 고가 대비, 외국인·기관 % 6, YoY 3, PER·PBR 변화 8, 괴리율, 목표가 변화 2, Fwd PER 변화 2, 신용/공매도/대차 4). 수준 값(현재가·시가총액·거래대금·PER·PBR)은 칠하지 않는다.
- 열마다 기준점 = `유니버스 = 대회` 행만의 최솟값·중앙값·최댓값(낮음 초록 `#63BE7B` → 중앙 노랑 `#FFEB84` → 높음 빨강 `#F8696B`). 유니버스 밖 행은 기준 계산에서 빼되 같은 기준으로 칠하고, 기준을 넘으면 끝 색으로 고정된다. 공란은 칠하지 않는다.
- 최근 20일 줄무늬는 20칸 전체(대회 행)를 하나의 척도로, 기준점은 5·50·95 백분위. 같은 값은 어느 날짜 칸이든 같은 색이다.
- 업종 페이지: KRX 업종 표는 `구분 = 업종` 행만, 테마 집계는 세부테마 행만으로 기준점을 잡는다.

## 버튼 결과 판정

- 단계별로: 새로 고침 자체가 오류를 냈거나 그 표의 `상태`가 하나라도 `이전 데이터`로 시작하면 **실패**. `오류:`로 시작하는 행이 있으면 **일부 오류** — 종목코드 열이 있는 표는 서로 다른 종목 수, 없는 표는 행 수를 센다. 그 밖(`OK`·`데이터 없음`·`추정 없음`, 0행 표 포함)은 **정상**. 토큰 단계는 새로 고침 뒤 만료까지 5분 이상 남은 토큰이 없으면 실패.
- 상태 칸: 실패가 하나라도 있으면 `실패: <단계들> — 이전 데이터 표시 중`, 아니면 일부 오류 합계 `일부 오류 n건`, 아니면 `정상`. 최근 조회 칸에는 버튼 실행이 끝난 시각.
- 실패한 표는 직전 데이터를 유지하고 상태에 사유를 남긴다. 한 단계가 실패해도 다음 단계로 진행한다.
- **주간 항목**(분기 실적·신용/공매도/대차·목표주가와 KIS 추정의 전체 재조사)은 항목별 마지막 성공 후 `weekly_days`(기본 7) 달력일이 지났거나 `force_weekly = Y`이거나 새 종목·직전 오류 종목일 때만 [전체]에서 조회한다. [전체]가 끝나면 `force_weekly`는 N으로 돌아간다(Esc로 취소하면 그대로). 평소 [전체]의 목표주가·추정은 직전 전체 조사에서 값이 있던 종목만 다시 받는다.

## 사용자 데이터 보존

- 재생성 때 매매일지 전체·관심종목·설정(기존 키는 사용자 값 유지, 새 키는 기본값 추가)·해외지수 목록·휴장일·수정표·가격 이력·세션 달력·분기 실적·신용/공매도/대차·추정 스냅샷·유효한 토큰이 이관된다. 이관할 입력이 있으면 샘플 데이터를 넣지 않는다.
- 스냅샷이 원본에 없으면 통합문서 옆 `history/est_snap.csv`에서 복원한다. 원본을 읽을 수 없으면 새로 만들지 않고 멈춘다(`--no-migrate`를 줬을 때만 새로).
- 어떤 파일도 백업 없이 지우거나 덮지 않는다. `.xlsx` 원본은 이관 성공 뒤에만 백업 폴더로 옮긴다. 알 수 없는 사용자 시트는 경고만 하고 옮기지 않는다(백업본에 남음).
