## 3. 작업 중 발견한 동작과 해결

1. **새로 고침 직후 Excel이 쿼리를 한 번 더 평가한다** (최상위 단계도 따로). 캐시에 없는 요청은 KIS로 다시 나가서, 조회가 값 단계에 있으면 build 모드(버튼 아님)에서도 호출되고 버튼 한 번에 호출이 두 배가 됐다(요청 수를 세는 모의 서버로 측정). → 모든 버튼 쿼리에서 조회를 함수로 감싸 해당 모드에서만 부르고, `tblRunCtl`의 `started`(버튼 시작 시각)보다 자기 표의 조회시각이 늦으면 다시 조회하지 않게 했다. 통합문서를 연 뒤 첫 활성 새로 고침은 그래도 겹칠 수 있어 [전체]는 아직 새로 고치지 않은 표를 build 모드로 한 번 미리 새로 고친다(표별 추적).
2. **Power Query 표에 조건부 서식을 걸면** 기본 새로 고침 방식(셀 삽입/삭제)에서 0~1행 → N행으로 늘 때 서식 범위가 깨지고, 규칙이 많으면 새로 고침 중 Excel이 멈춘다. 0행 새로 고침은 셀을 지워 아래 표를 끌어올린다. → 페이지 표는 적재 직후·첫 새로 고침 전에 `RefreshStyle = 0`(덮어쓰기)으로 바꾸고(`prepare_tables`), 쌓인 표에는 임시 행 추가·삭제를 하지 않는다.
3. **`fnFallback`(직전 표 유지)의 결과는 열 형식이 없어** 날짜가 일련번호로 보였다 → 대체 결과에 형식을 다시 입힌다.
4. **`List.Buffer`·`Table.Buffer`는 항목 안의 오류를 올리지 않고 빈 행으로 적재**한다 → 종목별 `try` 안에서 값을 강제 평가한다.
5. **VBA 소스는 이 PC에서 cp949로 저장**돼 `—`·`✓` 같은 문자가 `?`가 된다 → `ChrW`로 만들고, 삽입기는 cp949로 못 쓰는 문자가 있으면 거부한다.
6. **AccessVBOM은 Excel 인스턴스가 시작될 때 한 번 읽힌다** → 빌드는 Excel 시작~종료 전체를 '켜기 → 복원' 블록 안에서 한다.
7. **나란히 놓인 같은 수준의 열 묶음은 하나로 합쳐진다** → 각 접기 묶음의 첫 열 하나를 보이게 둔다(최근분기·PER변화3M·신용잔고율·다음이벤트·NICS 대분류·유의).
8. **Q.Pack 기준점 수식이 1행 표에서 0이 되는 문제**(COUNT가 FALSE를 셈) → 페이지별로 막았다.
9. **KIS 동작**: 종목별 투자자 일별 API는 오늘 날짜를 15:40 전에는 거부(OPSQ2001) / 예탁원 상장정보 연속 조회가 넘어가지 않고, 종목투자의견은 `tr_cont`가 비어 있어 날짜 분할로 받음 / 멀티 시세 `inter2_sdpr` = 기준가(분할 반영 전일 종가), `inter2_prdy_clpr` = 원 전일 종가 / 없는 종목코드는 오류 대신 0값 응답 / 오늘 KOSPI 일봉은 10:50·11:37에 이미 존재(처음 생기는 시각은 미측정).
10. **Excel의 백그라운드 새로 고침 완료 확인 타이머**가 1 → 5 → 20초로 늘어나, 시험 도구는 자기 Excel 창에만 타이머 메시지를 보내 0.2초로 줄였다.
12. **최종 검토에서 고친 것**: 현재 후행 PER·PBR에도 공시 지연을 적용하던 계산을 사양대로 바꿈(현재값은 최근 4개 분기·최근 BPS, 지연은 변화 계산에만) / 수정표에서 종목DB에 없는 코드를 실제로 무시(경고 칸과 같은 규칙, 한국어 Excel `CHAR(160)`이 일반 공백이라 `UNICHAR(160)` 사용) / [전체] 준비 뒤 '15초 + 준비 시간' 대기(고정 15초는 실행당 135회 중 81회 중복, 이 방식은 0회) / 이력 CSV는 행 수가 줄면 덮지 않고 날짜 붙인 파일로 따로 저장 / 뉴스 대체 경로의 날짜 형식 / 숨은 `--resume`이 실제 통합문서를 덮지 못하게 / 코드 주석의 기획 문서 번호를 내용으로 정리.
11. **통합 검증에서 고친 매크로 결함 3건**: [전체]가 앞선 다른 버튼 뒤에 눌리면 자기 표 준비를 건너뛰던 문제(표별 추적으로), [시세]·[업종]의 준비 시간이 막는 중복 호출보다 비쌌던 문제(준비는 [전체]만), 시작 시각이 초 단위라 테마 집계가 한 박자 늦던 문제(다음 초까지 기다린 뒤 기록).

## 6. 설계와 다르게 하거나 해석한 점

- 대회 종목 수 527(예상 490~500은 하루 기준 어림). 규칙은 그대로.
- [대회종목]에서 접기 묶음마다 첫 열 하나를 보이게 둠(Excel 열 묶음 병합 때문).
- 수정표는 [설정] W8(기존 입력표 아래에 두면 관심종목 등의 행 삽입·삭제가 막힘).
- [시장] 순위 블록을 한 줄에 2개로(★ 칸을 넣으면 종목명·섹터가 잘려서). 증시 자금 차트는 60일 시작 대비 % 변화(금액 그대로는 선이 평평).
- 시세판의 추정가집계는 장중(평일 09:00~15:30)에만 표시. ROE는 최근 분기 행의 값. KIS 추정이 FY1만 있으면 FY2 칸에 'FY1만'. 테마 대분류 이름은 '전력·원전' 대신 '전력·에너지'(태양광·ESS 포함, 원전은 세부테마).
- 목표가: 0·공란은 건너뛰고 증권사별 마지막 실제 목표가, 최근 의견은 조회 기간(약 9개월) 전체 기준, 주간 규칙은 달력일 기준.
- 증시 자금 표는 `_calc` 시트(`_data`에 두면 기존 표의 계산열과 충돌).

- 종목분석 60세션 매물대: 각 세션의 거래량을 그날 고가~저가 범위에 고르게 퍼뜨리고, 구간과 겹치는 길이에 비례해 나눈다(범위 안 균등 밀도로 해석).
